# 🌦️ Weather Connect

Weather Connect is a modern web application that provides **real-time weather information and hourly forecasts** for any city. Users can enter a city name to view the **current temperature and weather conditions along with a 24-hour forecast in 3-hour intervals**.

## 🔗 Live Demo
https://weatherconnect-qscfbkkc1-yalamanchili-siddharthas-projects.vercel.app/

---

## 📌 Features

- 🌍 Search weather for **any city worldwide**
- 🌡️ Displays **real-time temperature**
- ☁️ Shows **weather condition (clear sky, rain, clouds, etc.)**
- ⏱️ **24-hour forecast** in **3-hour intervals**
- 🎨 Modern **glassmorphism UI design**
- 📱 Responsive interface
- ⚡ Fast weather data retrieval using API

## ⚙️ How It Works

1. User enters a **city name**.
2. The application sends a request to the **OpenWeatherMap API**.
3. The API returns:
   - Current temperature
   - Weather condition
   - Hourly forecast data
4. The app displays the **current weather and upcoming 24-hour forecast**.
